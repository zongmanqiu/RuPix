# patches/ —— 第三方库补丁登记（windui 卷 + usvg 卷）

本目录登记对仓库外第三方源码（`.3rd/wind-ui-rust-0.23.0`，本地 path 依赖）的
**修改后完整文件**与登记簿。机制照抄 CurSeen 第七章：

## 生命周期

```
发现上游缺陷 → 在 .3rd/ 里就地修（源码标注 ★ RuPix 补丁 0NN）
→ 把修改后的**完整文件**归档到 patches/<库名>-<版本>/
→ PATCHES.md 登记（编号 0NN 递增、永不删节）
→ docs 门禁双向核对：源码 ★ 标记 ↔ PATCHES.md 章节
```

## 两条硬约束

1. **只增不减**：补丁章节只追加；登记簿章节永不删节。
   （0.23.0 起不再归档 `before/` pristine 基线——0.23.0 是在用户下载的上游源码上
   原地打补丁的，没有留下原始副本；日后升级 diff 请对照上游 release tarball。
   0.20.0 的库与归档已按 2026-10-13 裁决删除，重放依据在 PATCHES.md 各章节。）
2. **禁止反向覆盖**：不得把 `.3rd/` 的文件复制回归档目录之外的方向；
   `.3rd/` 是「工作副本」，`patches/` 是「权威归档」，重装/重放下靠 `patches/` 单向重放恢复。
