# 排版规范（字体 / 字号 / 字重）

> **正本**。改字体或字号先改这里，再改 `src/ui/tokens.rs`；代码与本文不一致时当场二选一。
> 落地实现：`src/ui/tokens.rs`（令牌）与 `runtime` 里的 `Theme::font_family`（框架兜底）。
> 门禁：hygiene 第十六查 `literal_font`——ui 层写死字体/字号/字重就红。
> 关联：版式（留白 / 行高 / 按钮位）见 `docs/界面版式规范.md`。

## 一、一条规则

**看图窗口与设置窗、对话框共用同一个字体族、同一个正文字号。**

- 层级只用**加粗**表达（卡片名、小节标题、选中项）；
- 特殊用途只允许**更大**字号，而且必须先在 §3 登记；
- 不允许出现「这一块小一号更合适」的临时决定——那正是本轮返工的起因。

2026-11-14 用户口径：「所有字体字号全部都要统一……包括标题栏，按钮栏左侧，信息面板，
图标数字……某些特殊用处的可以加粗，也可以更大的字号，但必须记录在文档里面。
我们的口子不能随便开。」

## 二、令牌表

| 令牌 | 值 | 用在哪 |
|---|---|---|
| `FAMILY_UI` | `Microsoft YaHei` | **全部正文**：标题栏、浮条与状态、信息面板、文件树、缩略图序号、设置页、对话框、插件输出卡 |
| `SIZE_BODY` | `13` | **全部文本**的唯一字号（与上一行同域） |
| `FAMILY_ICON` | `Segoe MDL2 Assets` | **只画图标字形**（PUA 码位），不画任何正文 |
| `SIZE_ICON` | `16` | 图标字形的统一光学尺寸 |
| `WEIGHT_EMPHASIS` | `600` | 卡片名 / 小节标题 / 选中项：只加粗，不换字体、不换颜色 |
| `SIZE_DISPLAY` | `22` | 登记例外专用（见 §3） |

框架侧的兜底：`runtime` 把 `Theme::font_family` 设为 `FAMILY_UI`，于是 windui 自绘的
右键菜单、tooltip、toast，以及任何没显式设 `font_family` 的文本都落到同一枚字体上。
**普通文本不再逐个写 `.font_family(...)`**——只有图标字形显式写 `FAMILY_ICON`。

字号取 13（而不是框架默认的 14）：信息面板在 2026-11-14 已按 13 校准，看图窗口的
标题栏与状态本来也是 13；统一到已成型的这一档，改动面最小、观感不变。

## 三、例外登记表

| 用途 | 取值 | 落点 | 理由 |
|---|---|---|---|
| 图标字形 | `FAMILY_ICON` + `SIZE_ICON`(16) | `ui/chrome.rs`、`ui/info_panel/mod.rs`、`ui/settings/extensions_tab.rs` | 图标不是文字；MDL2 字形在 13px 下偏小，16 与按钮盒子匹配 |
| 品牌名「RuPix」 | `SIZE_DISPLAY`(22) | `ui/settings/about.rs` | 关于页展示性标题，全页唯一 |
| 翻页箭头 ‹ › | `SIZE_DISPLAY`(22) | `ui/chrome.rs` | 箭头是直径 38px 圆的视觉主体，22px 才撑满；用界面正文字体，不另引字体 |
| 框架菜单文字 | windui 0.35 起 = 主题正文字号度量 `font_md`（默认 14.0） | `.3rd/wind-ui-rust-0.35.0/src/app/menu.rs`（`menu_font()`） | 0.23 的硬编码 `MENU_FONT`=13.5 已被上游移除，0.35 改跟随主题正文字号（`font_md` 默认 14.0，定义在 windui 的 theme 模块）；宿主未覆盖该度量，菜单文字实际渲染 14.0，比 0.23 大半号——本仓不复制这个数 |

新增例外的流程（缺一不可）：

1. 在 `ui/tokens.rs` 起一个**语义名**（`SIZE_XXX` / `FAMILY_XXX`），不写裸数字；
2. 在上表加一行：用途、取值、落点、理由；
3. 消费点只引用令牌；再跑 `python build/hygiene_scan.py`。

只允许「加粗」或「更大」。要更小，先停下来问：是不是版式该改，而不是字号该开洞。

## 四、实施纪律

1. 新元素取字号/字重一律 `use super::tokens::{SIZE_BODY, WEIGHT_EMPHASIS, …}`。
   自绘文字用 `TextStyle::new(SIZE_BODY)`；`Element` 用 `.font_size(SIZE_BODY)`。
2. 小标题只加 `WEIGHT_EMPHASIS`，不换字体、不改颜色、不缩字号。
3. 正文不写 `.font_family(...)`。需要图标时写 `.font_family(FAMILY_ICON)`。
4. 选择要换字体/字号：只改 `ui/tokens.rs` 的常量（以及本表），所有消费点跟着走。
5. 门禁失败时不许绕：`literal_font` 命中的行就是“又抄了一个数”，改成令牌。

## 五、机器执行

- `python build/hygiene_scan.py --selftest`：`literal_font` 正反样例（字面字号 /
  `TextStyle::new(数字)` / `font_family("…")` / `font_weight(数字)` 命中；令牌引用不命中）。
- `python build/hygiene_scan.py`：`src/ui/**/*.rs`（`ui/tokens.rs` 除外）清零。
- 视觉回归清单：标题栏、浮条状态与悬停提示、信息面板（图片信息 / 插件卡）、
  文件树、缩略图序号、设置页、关于页、三扇自绘对话框。
